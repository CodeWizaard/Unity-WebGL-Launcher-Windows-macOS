Первый выпуск Unity WebGL Launcher.

- Одно окно: выбор HTML/папки, запуск, остановка и открытие браузера.
- Режимы «Только этот компьютер» и «Телефон по Wi-Fi», копирование адреса.
- Gzip, Brotli, Unity Decompression Fallback и COOP/COEP.
- Windows x64, macOS Intel и Apple Silicon; Python устанавливать не нужно.

Скачайте ZIP под свою систему и распакуйте. Архивы содержат приложение, README и MIT-лицензию. Рядом опубликованы SHA-256.

Сборки не подписаны сертификатом разработчика; macOS-сборки не нотарифицированы. Автоматически проверены запуск окна и работа сервера, но это не ручная проверка настоящего Unity-билда на каждой платформе. Для телефона по HTTP используйте Gzip или Decompression Fallback; многопоточность требует HTTPS.
