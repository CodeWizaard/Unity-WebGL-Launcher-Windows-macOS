Первый выпуск Unity WebGL Launcher.

- Одно окно: выбор HTML/папки, запуск, остановка и открытие браузера.
- Режимы «Только этот компьютер» и «Телефон по Wi-Fi», копирование адреса.
- Gzip, Brotli, Unity Decompression Fallback и COOP/COEP.
- Windows x64; Python устанавливать не нужно. Выпуск macOS отложен.

Скачайте Windows ZIP и распакуйте. Архив содержит приложение, README и MIT-лицензию. Рядом опубликована SHA-256.

Сборка не подписана сертификатом разработчика. Автоматически проверены запуск окна и работа сервера. Для телефона по HTTP используйте Gzip или Decompression Fallback; многопоточность требует HTTPS.
