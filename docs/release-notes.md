В режиме **Телефон по Wi-Fi** лаунчер объясняет, почему в списке может быть несколько ссылок. Они открывают один билд по разным сетевым адресам компьютера. Если первая ссылка недоступна с телефона, выберите другую. QR-код и кнопка **Копировать** используют выбранную ссылку.

- macOS: отдельные ZIP для Apple Silicon (arm64) и Intel (x64).
- Windows x64 также включён в выпуск.
- Для macOS автоматические проверки выполняются на macOS 15. Более старые системы не проверены.

Распакуйте соответствующий ZIP. Python устанавливать не нужно.
macOS-приложение не подписано Developer ID и не нотарифицировано Apple: Gatekeeper может запросить разрешение или заблокировать запуск. Windows-сборка также без доверенной подписи издателя.
