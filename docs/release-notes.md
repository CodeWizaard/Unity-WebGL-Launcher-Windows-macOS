Unity WebGL Launcher 1.0.1 — обновлённая иконка Windows.

- Одно окно: выбор HTML/папки, запуск, остановка и открытие браузера.
- Режимы «Только этот компьютер» и «Телефон по Wi-Fi», копирование адреса.
- Gzip, Brotli, Unity Decompression Fallback и COOP/COEP.
- Windows x64; Python устанавливать не нужно. Выпуск macOS отложен.
- Новая иконка для EXE, окна и панели задач, с размерами от 16 до 256 пикселей.
- Добавлены сведения о приложении и версии в свойствах EXE.

Скачайте Windows ZIP и распакуйте. Архив содержит приложение, README и MIT-лицензию. Рядом опубликована SHA-256.

Сборка пока не подписана сертификатом разработчика: предупреждение SmartScreen может сохраняться. Новая иконка и сведения о версии не заменяют цифровую подпись. Автоматически проверены запуск окна и работа сервера. Для телефона по HTTP используйте Gzip или Decompression Fallback; многопоточность требует HTTPS.
